## 重構目標

專案在功能開發階段遺留多個導航與重定向問題，且各頁面樣式各自定義，缺乏統一設計 token；此外，資料庫帳密與 JWT 密鑰直接寫在 `application.properties`，有外洩風險。

本次修復的目標是：**修正導航邏輯、統一全站樣式、遷移機密資訊至環境變數，提升使用者體驗、程式碼可維護性與安全性。**

## 現況事實（已查證）

- 前端 Angular 19 + Angular Material + SCSS
- 後端 Spring Boot（Java / Gradle）+ JWT 認證
- 登出後頂部選單未切換為登出狀態
- 登入成功後未正確重定向至主頁面
- 點擊「動態調查」主按鈕導向登入頁面
- 全站 SCSS 樣式各自定義，沒有統一 token
- 資料庫帳密與 JWT 密鑰寫死在 `application.properties`，已進版控
- 資料夾名稱使用大寫（`BackEnd`、`FrontEnd`），不符業界慣例

## 已決定的決策

| #   | 決策                                                     | 理由                                                              |
| :-- | :------------------------------------------------------- | :---------------------------------------------------------------- |
| 1   | **登出時清除 localStorage token，並導向登入頁**          | 只清後端 session 不夠，前端狀態也要同步清除，頂部選單才會正確切換 |
| 2   | **登入成功後呼叫 `router.navigate(['/dashboard'])`**     | 登入成功只更新 token 狀態不夠，必須主動導航至主頁面               |
| 3   | **修正主按鈕的路由路徑**                                 | 路由 Guard 判斷錯誤，導致主按鈕指向登入頁                         |
| 4   | **統一全站 SCSS 樣式**                                   | 各頁面重複定義樣式，維護成本高且視覺不一致                        |
| 5   | **將機密資訊遷移至 `.env`**                              | 避免密碼與 JWT 密鑰進版控，降低外洩風險                           |
| 6   | **建立 `.env.example` 作為範本**                         | 讓其他人知道需要設定哪些環境變數                                  |
| 7   | **資料夾名稱統一改為小寫**                               | 符合業界慣例，避免跨平台大小寫問題                                |
| 8   | **更新 `.gitignore`，擋掉 `.env`、`bin/`、`.DS_store/`** | 避免機密與編譯產出進版控                                          |
| 9   | **移除已被追蹤的 `.DS_Store`**                           | 系統檔案不該進版控                                                |

## 驗證方式

- 登出後確認頂部選單顯示「登入」按鈕，localStorage 無 token
- 登入成功後確認畫面跳轉至主頁面
- 點擊主按鈕確認跳轉至首頁
- 檢查所有頁面的顏色、間距、字級是否一致
- 確認 `.env` 被 `.gitignore` 擋掉，`.env.example` 有進版控
- 確認 `application.properties` 改用環境變數，沒有寫死機密
- 確認資料夾名稱為小寫
- 確認 `.DS_Store` 已從版控移除，且 `.gitignore` 有擋掉 `.env`、`bin/`、`.DS_Store`
